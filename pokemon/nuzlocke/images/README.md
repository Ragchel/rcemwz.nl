# Nuzlocke journal images

Keep images used by the Nuzlocke journal in this directory. Give every run its own
subfolder, matching the run page slug (for example `emerald-run-1/`). Pokémon
portraits are optional, but should be optimized for the web and have meaningful
alternative text on the run page.

## Black run 1 artwork

Locally stored Pokémon artwork from the PokéAPI sprites repository:

- `black-run-1/snivy.png`: https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/495.png
- `black-run-1/lillipup.png`: https://raw.githubusercontent.com/PokeAPI/sprites/master/sprites/pokemon/other/official-artwork/506.png

Pokémon artwork belongs to its respective rights holders. These images are reused
in the journey notes and team section; visitors do not need to load third-party images.
