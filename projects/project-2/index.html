The story

Why I made it

Power Stones don't come cheap in The Tower. Spending resources efficiently actually matters here, so I built this to stop guessing: load a save, see exactly where you stand, and find the cheapest combination of levels and substats that actually gets you to permanent uptime.

The details

How it came together

Built with thetowersdk to read a Chrono Field loadout straight from a player's save file. Everything runs client-side in the browser; the save file is never uploaded anywhere.
